# NPS City

NPS City is an isometric city-building game adapted for an employee engagement challenge. Players design their own land, balance power generation, industrial estates, community growth, environment, services, and city finances.

The game is built for a 14-day campaign, with Thai onboarding, NPS challenge missions, faster economy tuning, and a starter-city option for first-time players.

## Features

- Isometric city-building canvas with roads, zoning, utilities, services, parks, transport, and animated city life.
- Thai-first game UI and onboarding flow.
- Mandatory first-start choice: build manually or generate a starter city.
- NPS Challenge panel with missions, rewards, score tracking, and 14-day competition rules.
- Power plant question popup placeholder, ready for real NPS knowledge questions.
- Netlify-ready build configuration.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- HTML5 Canvas

## Getting Started

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start the production build:

```bash
npm run start
```

## Deploying To Netlify

This project includes `netlify.toml`.

Netlify build settings:

- Build command: `npm run build`
- Publish directory: `.next`
- Node version: `22`
